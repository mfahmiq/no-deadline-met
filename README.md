# One Line, No Deadline Met

Entry for the make.fun competition
[One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce):
a single-line joke excusing a missed deadline, capped at 200 characters.

## The entry

> I didn't miss it, I just rescheduled it in my head and forgot to tell anyone.

(77 characters — one line, one sentence, punch at the end.)


## How to run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output`). The program embeds the entry text verbatim; it makes no
network calls, reads no files, and needs no secrets.

## Files

- `entry.txt` — the entry itself, exactly as submitted.
- `main.py` — writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
- `README.md` — this file.
